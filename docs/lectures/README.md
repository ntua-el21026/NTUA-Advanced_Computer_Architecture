# Lecture Slides

This directory contains the course lecture PDFs used as background material for
the assignments.

## Topics

- Overview, superscalar/VLIW execution, dynamic scheduling, branch prediction,
  speculation, SIMD, and simulation.
- Thread-level parallelism, GPU/loop-level parallelism, cache coherence,
  memory consistency, and interconnection networks.

The slides are kept as immutable reference material; exercise-specific notes
are in each exercise's `theory.md`.
