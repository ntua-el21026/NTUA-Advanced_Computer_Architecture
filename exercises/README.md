# Exercises

This directory contains the three coursework assignments in a consistent
layout. Each exercise is self-contained and includes the official handout,
helper code, automation scripts, generated benchmark summaries, diagrams, and
the final report.

## Contents

- `1st/`: branch statistics and branch prediction with Intel PIN.
- `2nd/`: cache hierarchy simulation and replacement-policy evaluation.
- `3rd/`: synchronization, cache coherence, Sniper 8.0, McPAT, and
  real-machine scalability.

## Common Layout

Each exercise uses these directory names where applicable:

- `assignment/`: handout and reference material.
- `advcomparch-*-helpcode/`: provided code and local implementation changes.
- `scripts/`: automation for benchmark execution and summarization.
- `benchmarks/`: generated outputs, CSV summaries, text summaries, and plots.
- `report/`: LaTeX source and compiled PDF.
- `decisions.md`: implementation and methodology decisions.
- `theory.md`: notes used to support report writing.

Run scripts from the repository root unless a local README gives a more
specific command.
